# sonarc documentation

sonarc is a modeless terminal code editor for Linux servers, built for `ssh`
and `tmux`. These pages cover everything it does. They are also the website's
docs at <https://sonarc-dev.github.io/sonarc/docs/>, rebuilt on every change.

- [Getting started](getting-started.md): install, update, open a project, and check your terminal.
- [Keys](keys.md): every key, grouped by what you are doing.
- [Code navigation](navigation.md): definitions, references, and the indexes behind them.
- [Git](git.md): change marks, the Changes list, and diffs.
- [tmux and terminals](tmux.md): the settings that matter and what `-doctor` checks.
- [Troubleshooting](troubleshooting.md): clicks, keys, clipboard, and indexes that misbehave.
- [For vim users](vim.md): your habits, mapped to sonarc.
- [Design notes](design.md): how it stays fast on a kernel tree and never damages a file.
- [Contributing](../CONTRIBUTING.md): build, test, and send a change.

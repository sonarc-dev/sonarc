Terminal code editor · Linux & macOS

Find your way through huge codebases, over ssh.

sonarc is a modeless editor for code on remote machines. Ping a symbol and get its definition, references and callers back, from cscope, ctags or its own indexer. One static 4 MB binary, built to run inside tmux.

$curl -fsSL https://sonarc-dev.github.io/sonarc/install.sh | sh

No root needed; installs to ~/.local/bin. Or with Go: go install github.com/sonarc-dev/sonarc/cmd/sonarc@latest

Why sonarc

No modes

Typing inserts text. Ctrl+S saves and Ctrl+Z undoes. There is nothing to escape from and no :wq, so it works the way you already expect an editor to.

Made for tmux

tmux and screen drop Ctrl+Shift keys, so no command needs one: a Ctrl+K chord reaches everything. sonarc -doctor reads your live tmux settings and says what to change.

Scales to a kernel

A gigabyte tags file is binary-searched on disk instead of loaded. One cscope process stays resident, and the file tree reads a directory only when you open it.

What it does

  • Code navigationGo to definition, peek, find references, callers, callees, assignments and includers, with a jump-back stack.
  • Project searchText and regex search across the tree through git grep, and symbol search by name.
  • Changes and diffsThe files changed since the last commit sit under the tree. Select one to read its diff in place.
  • Sessions that survive sshOpen files, cursors and folders are saved every few seconds, so a dropped connection loses nothing.
  • Works with nothing installedWithout cscope or ctags, a built-in indexer still covers C and C++, Go and Python.
  • Mouse, themes, reloadClicks and the wheel work through tmux, five themes, and files changed on disk are noticed within two seconds.

Is it for you?

A good fit

  • You read and edit C on remote Linux machines: kernels, drivers, firmware, embedded.
  • You live in ssh and tmux and want an editor that behaves there.
  • You can't install much: no root, old glibc, Alpine, air-gapped boxes.

Not yet, if you need

  • Language servers, plugins or scripting.
  • Vim-style modal editing.
  • Split panes or rebindable keys. Both are planned.
